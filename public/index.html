SHOW THE FEED.

A simple tool to bypass social media login walls using Google as a proxy. Showing newest results from the last 7 days.

Try it: showthefeed.com/irishrail

The Problem

Public bodies are gating vital information behind private logins. If you don't have an account, you don't get the update.

The Bypass

X still allows Google to crawl public profiles. This tool redirects you to a chronological search of the last 7 days of tweets.
